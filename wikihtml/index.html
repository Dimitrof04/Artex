1.1 - Artex Folder

A Artex folder e a pasta que gerencia e organiza todo o sistema Artex em varias subpastas

Ela se localiza no root(/)

2.1 version

Esse comando mostra a versao atual do Artex e a ultima versao salva por voce (--build ou --save)

1.0.1

last save version : idk123

2.2 build

Esse e um dos comandos mais importantes para seu computador ele salva uma versao do seu computador usando git e .artex o processo acontece assim

# Update your system

yay -Syu # Update sys with yay

# Copyfiles (.config, artexbuild.json, more...)

# generation version

# commit (git) for save your version

2.3 save

Esse comando se reposabiliza por salvar uma versao manualmente criada por voce, para criar uma versao sua ate que e bem facil

Artex --save name

# e.. apenas troca "name" pelo nome da sua #versao

2.6 - --rollback

Retornar no ultimo save de forma rapida

2.7 - --rollback-git <N>

Faz o sistema retornar exatamente N commits atrás no histórico do Git e executa o build automaticamente.

Nota: Substitua <N> pelo número de versões que deseja voltar.

2.8 - --rollback-json <N>

Faz o sistema retornar exatamente N snapshots atrás através dos registros JSON e executa o build.

2.9 - --Create-artex

Comando utilizado para criar ou compilar um arquivo ou diretório inteiro para o formato compactado e proprietário .artex.

2.10 - --Rebuild-artex

Realiza a engenharia reversa ou descompactação de um arquivo com a extensão .artex, extraindo seu conteúdo original.

2.11 - --uninstall

Executa o script de remoção completa do ArtexRecovery, limpando os binários e dependências do sistema.
