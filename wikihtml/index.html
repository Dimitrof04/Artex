1.1 - Artex Folder

The Artex folder is the main directory responsible for managing and organizing the entire Artex system into multiple subdirectories.

It is located at root (/)

1.2 - git-saves

The directory where all your backups and system versions are stored and managed through Git. It tracks all full system history snapshots.

1.3 - json-saves

Stores the JSON state versions generated by ArtexBuild, providing structured build metadata.

1.4 - last-Backup

Unlike .artex builds, this directory only stores the single most recent modification made on your computer (the latest system state only).

1.5 - local-files

Directory dedicated to housing your local ArtexBuild files and any external files you wish to import.

1.6 - versions.txt

A plain text index file containing the full list of all saved versions recorded by Artex.

2.6 rollback

Quickly restores your system state to the latest saved snapshot.

2.7 rollback-git <N>

Reverts the system exactly N commits back in the Git history and triggers an automated rebuild.

Note: Replace <N> with the number of versions you want to rollback.

2.8 rollback-json <N>

Reverts the system N snapshot entries back using the JSON registry logs and triggers a rebuild.

2.9 Create-artex

Packs and compiles a target directory or file into the custom .artex compressed format.

2.10 Rebuild-artex

Decompresses and restores an .artex archive back to its original source structure.

2.11 uninstall

Executes the uninstallation procedure for ArtexRecovery, purging system binaries and related dependencies.

3.1 - ArtexBuild

The primary configuration and build module that constructs your entire system environment based on a structured .json configuration file.

3.2 - Build Process (processo)

When executing an ArtexBuild, the system performs the following steps in sequential order:

  1. User Data Backup: Copies user configuration directories and files.
  2. Artex Files Extraction: Copies essential Artex components and system configurations.
  3. Code Generation: Generates a unique tracking version code.
  4. Git Commit: Saves and commits the generated version directly to git-saves.
  5. Package Installation: Downloads and installs all packages defined under the "packages" key.
  6. System Update (Optional): Updates system repositories and installed packages.

3.3 - Artex Keys

hostname: "user" // your hostname

# Use hostnamectl in Linux terminal to check your current machine hostname

Defines your machine's target hostname. (You may comment or remove this key if you do not wish to modify the system hostname).
